## 2. Mandatory Product Goal Contribution & Value Generation Rules

Every story definition authored under the `product-owner` skill MUST explicitly include two mandatory sections:

1. **Product Goal Contribution:** Detail explicitly how the story advances omnidepot's master product goals (polyglot package repository hosting OCI/Maven/NPM, Evolutionary Modular Monolith on Java 25 LTS, zero vendor lock-in, 70%+ CAS deduplication, sub-millisecond hot-path streaming).
2. **Value Generation:** Detail explicitly the concrete business, operational, and developer efficiency value generated by delivering this story.

---

## 3. Standardized Story Definition Schema

Every story definition authored under the `product-owner` skill MUST adhere to the following template:

```markdown
### [STORY-XXX] <Story Title>

#### Context & Architecture Reference
> [!NOTE]
> Architectural decision records: <ADR-IDs>. Primary modules: `omnidepot-<module>`.

#### User Story
As **[<Persona Name> (<Role>)](file:///home/developer/projects/omnidepot/docs/architecture/stakeholders-personas.md#<fragment>)**, I want **omnidepot** to <capability>, so that <business value / objective>.

#### Product Goal Contribution
- **Master Goal Alignment:** <How this story directly advances polyglot registry capabilities, storage efficiency, or architecture goals>.

#### Value Generation
- **Developer & Operational Value:** <Quantitative or qualitative value generated for end users, platform ops, or security teams>.

#### Scope & Sub-modules
- `omnidepot-format-<name>`
- `omnidepot-core-domain`
- `omnidepot-core-api`

#### REST Endpoints & Key Invariants
- `<METHOD> /endpoint/path` (description)
- **Invariant:** <non-negotiable domain rule>

#### test-manager Protocol Verification Strategy (where applicable)
- **Level 1 (In-Memory Unit & Snapshot):** `<ClassTest>.java` (unit logic, deserialization, in-memory snapshot fixtures).
- **Level 2 (API Contract & Schema Fuzzing):** `<ClassContractCT>.java` (OpenAPI contract compliance, header fuzzing, error code matrix).
- **Level 3 (Black-Box E2E Native CLI via Testcontainers):** `<ClassNativeCliIT>.java` (Un-mocked native client execution inside Testcontainers).

#### Acceptance Criteria
- [ ] Requirement 1
- [ ] Requirement 2
- [ ] JSpecify `@NullMarked` on all package boundaries.
- [ ] Sub-30-second local test suite execution.
```
